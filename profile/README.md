## Build knowledge from ordinary files

doXmind is a desktop workspace for notes that stay portable. A Page is an ordinary `.md` or `.markdown` file, edited through a source-backed block editor. Your files remain readable and useful without doXmind.

Attachments such as PDFs, spreadsheets, images, and HTML files remain ordinary local files too. doXmind can inspect them and open them in their native apps; it does not turn them into a second, proprietary document format.

## Product boundary

We focus on a calm, local workspace for Markdown knowledge.

- **Local first:** no account, cloud sync, telemetry, or hosted user data.
- **Markdown is the source of truth:** edits write back to the original Markdown file while preserving unsupported syntax as raw Markdown.
- **Attachments stay attachments:** PDFs and spreadsheets are readable local files, not editors or new sidecar formats.
- **Desktop is Electron:** there is one supported desktop runtime.

doXmind does **not** provide cloud sync, AI runtime, collaboration services, PDF/Excel editors, or attachment sidecar writers.
